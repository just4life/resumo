# Resumo

Простой видеоплеер с современным тёмным интерфейсом. Написан на Rust, видео и звук
воспроизводит libVLC (движок из исходников VLC 3.x).

## Возможности

- **Плейлист**: файлы, папки, ссылки (http, rtsp, udp…), перетаскивание в окно,
  повтор (весь список / один трек), перемешивание, сохранение и загрузка M3U,
  переход к следующему файлу по окончании.
- **Стримы Twitch**: ссылка на канал вида `https://www.twitch.tv/канал`
  открывается как обычное видео, в лучшем качестве. Если канал не в эфире,
  плеер так и скажет.
- **Видео и эфиры YouTube**: ссылки вида `https://www.youtube.com/watch?v=…`,
  `https://youtu.be/…`, Shorts и эфиры открываются как обычное видео, до 1080p,
  с названием с YouTube; ссылка на канал (`https://www.youtube.com/@канал`)
  открывает его текущий эфир. Вход в аккаунт не поддерживается, поэтому видео
  с ограничением по возрасту не откроются
- **Чат Twitch**: вместе со стримом показывается его чат, только для чтения
  и без входа в аккаунт. При открытом плейлисте чат занимает его место, иначе идёт текстом
  поверх видео слева.
  Включается и выключается кнопкой чата в панели управления; выбор запоминается.
- **Прямые эфиры** (Twitch и другие HLS-потоки): вместо времени метка LIVE,
  без выдуманной длительности. Кнопки ±10 с и полоса перемотки отматывают назад в пределах того,
  что отдаёт сам поток (на Twitch около 15 секунд); рядом показано отставание
  от эфира, а нажатие на него возвращает в эфир.
- **Аудиодорожки**: выбор дорожки, отключение звука, задержка звука.
- **Субтитры**: встроенные дорожки, загрузка внешнего файла (srt, ass, ssa, vtt, sub…),
  задержка и размер субтитров (в меню «Субтитры»). Субтитры можно поднять или
  опустить, перетащив мышью по видео с зажатым Shift; размер и положение
  запоминаются. Файл субтитров можно просто перетащить в окно.
- **Кадрирование**: 16:9, 16:10, 4:3, 5:4, 1:1, 1.85:1, 2.35:1, 2.39:1, 9:16
  и ручная обрезка каждого края в процентах.
- **Звук**: выбор устройства вывода (колонки, наушники, HDMI) в меню правой кнопки,
  громкость до 150 %, регулировка колёсиком мыши над видео (шаг 5 %).
- **Продолжение просмотра**: плеер запоминает, где остановлено каждое видео,
  и при следующем открытии продолжает с этого места. Досмотренное до конца
  начинается сначала. Громкость и выбранное устройство тоже запоминаются.
- **HDR-видео на обычном экране**: HDR10 и HLG (mkv, webm, mp4, mov) плеер
  распознаёт сам и переводит в обычную картинку (SDR) на видеокарте, поэтому
  HDR в Windows можно не включать. Без этого HDR-видео выглядит блёклым и серым.
  Для такого видео в панели появляется кнопка «HDR»: в ней видно тип и пиковую
  яркость, ползунок «Яркость» (по умолчанию картинка как в PotPlayer), и там же
  преобразование можно выключить (то же в меню правой кнопки).
- **Сохранение кадра**: пункт «Сохранить кадр» в меню правой кнопки или Ctrl+E.
  Кадр сохраняется в PNG в исходном разрешении видео (с кадрированием и
  субтитрами, как на экране; HDR уже переведён в обычную картинку) в папку
  «Изображения\Resumo». Пункт «Папка с кадрами» открывает её в проводнике.
- **Клип из видео**: пункт «Сделать клип» в меню правой кнопки или клавиша I
  отмечает начало. Дальше видео просто смотрят: пауза отмечает конец, и над
  панелью управления появляется предложение сохранить клип. Начало и конец
  можно поправить (перемотать и нажать «Начало» / «Конец» либо I / O), кнопка
  «Просмотр» проигрывает отмеченный кусок, отмеченный участок виден на полосе
  перемотки. Клип сохраняется за секунды и без потери качества, потому что
  видео и звук копируются как есть, без перекодирования: в MP4, если кодеки
  это позволяют (H.264 / HEVC и AAC, AC-3, E-AC-3, MP3), иначе в MKV. В клип
  попадает выбранная звуковая дорожка, без субтитров. Копия может начаться
  только с ключевого кадра, поэтому клип иногда начинается на пару секунд
  раньше отметки. Файлы лежат в «Видео\Resumo»; пункт «Папка с клипами»
  открывает её в проводнике.
- Меню правой кнопки слегка прозрачное, как и панель управления.
- Скорость 0.25×–3× (в том числе 1.15×), полноэкранный режим, контекстное меню по правой кнопке на видео.

## Интерфейс

- Кнопки сгруппированы в полупрозрачные капсулы поверх видео, как в YouTube,
  без затемнения кадра. Пока видео играет, а мышь не двигается, они и курсор скрываются.
- Рядом с кнопкой воспроизведения: перемотка на 10 с назад и вперёд, а при
  нескольких видео ещё и переход к предыдущему / следующему.
- Кнопка с папкой в панели открывает файлы, папки и ссылки.
- Если открыть файл из проводника, плеер сразу показывает видео без плейлиста;
  плейлист открывается кнопкой в панели или клавишей L.
- **Информация о видео** по Tab: кодеки видео и звука, разрешение, частота
  кадров, битрейт.
- **Ускорение ×2 при удержании**: зажмите кнопку мыши на видео, и оно играет
  вдвое быстрее, пока кнопка зажата (как на YouTube).
- Окно подстраивается под размер открытого видео, но не больше экрана.
- Рамка окна своя, в теме плеера: окно перетаскивается за заголовок или за само
  видео, двойной щелчок по заголовку разворачивает окно, размер меняется за края.
- В Windows под превью окна на панели задач есть кнопки «предыдущий»,
  «пауза / воспроизведение» и «следующий», как у Spotify.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | пауза / воспроизведение |
| ← / → | −5 / +5 с (с Shift: 30 с) |
| ↑ / ↓, колёсико | громкость |
| M | без звука |
| N / P | следующий / предыдущий |
| A | следующая аудиодорожка |
| S | следующие субтитры |
| C | следующий режим кадрирования |
| L | показать / скрыть плейлист |
| F, F11, двойной клик | полный экран (Esc — выйти) |
| Ctrl+O | открыть файлы |
| Ctrl+E | сохранить кадр |
| I / O | начало / конец клипа (Esc — отменить клип) |
| Tab | информация о видео |

## Готовые сборки

- `dist/Resumo-Setup-0.1.0.zip` (внутри `Resumo-Setup-0.1.0.exe`) — установщик для Windows 10/11 (64-бит).
  Ставит плеер в `Program Files\Resumo`, создаёт ярлыки и регистрирует Resumo
  для видео (mkv, mp4, avi, mov, webm, ts и др.), по желанию и для музыки.
  Windows 10/11 не позволяют программам молча назначать себя плеером по умолчанию,
  поэтому в конце установщик открывает «Приложения по умолчанию»: там нужно
  выбрать Resumo. Удаляется через «Установленные приложения» и возвращает
  прежние ассоциации. Тихая установка: `Resumo-Setup-0.1.0.exe /S`.
- `dist/Resumo-windows-x64.zip` — переносная версия без установки: распаковать
  и запустить `Resumo\resumo.exe`. libVLC и плагины уже лежат рядом, VLC ставить не нужно.
- `dist/resumo-linux-x64` — для Linux, нужен установленный VLC
  (`sudo apt install vlc` или `libvlc5 vlc-plugin-base`).

## Сборка из исходников

Нужен свежий Rust через `rustup` (проверено на 1.97).

**Linux**

```sh
sudo apt install libvlc-dev vlc-plugin-base
cargo build --release
./target/release/resumo video.mkv
```

**Windows (MSVC)**

1. Установить VLC 3.x (64-бит) или скачать NuGet-пакет `VideoLAN.LibVLC.Windows`.
2. Указать папку с `libvlc.lib`:
   `set VLC_LIB_DIR=C:\путь\к\build\x64` (для установленного VLC — его папка `sdk\lib`).
3. `cargo build --release`
4. Положить рядом с `resumo.exe` файлы `libvlc.dll`, `libvlccore.dll` и папку `plugins`.

**Windows (кросс-сборка из Linux)**

```sh
sudo apt install gcc-mingw-w64-x86-64 nsis zip
rustup target add x86_64-pc-windows-gnu
VLC_LIB_DIR=/путь/к/VideoLAN.LibVLC.Windows/build/x64 sh installer/build-windows.sh
```

Скрипт собирает `resumo.exe`, переносной zip и установщик
(`installer/resumo.nsi`, NSIS 3) в папку `dist/`.

**macOS**

Установить VLC.app в `/Applications`, затем `cargo build --release`.
Библиотека берётся из `/Applications/VLC.app/Contents/MacOS/lib`; если плагины
не находятся, запускать с `VLC_PLUGIN_PATH=/Applications/VLC.app/Contents/MacOS/plugins`.
Сборка под macOS не проверялась.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/vlc.rs` | привязки к C API libVLC (`extern "C"`) и безопасные обёртки |
| `src/video.rs` | приём кадров из потока libVLC (RGBA, для HDR — 10-битные P010) |
| `src/hdr.rs` | распознавание HDR по данным файла (mkv, mp4, HEVC) |
| `src/hdr_gl.rs` | шейдер HDR → SDR: PQ/HLG, сжатие светов по BT.2390, BT.2020 → BT.709 |
| `src/app.rs` | окно, панель управления, меню, плейлист |
| `src/info.rs` | строки информации о видео (Tab) |
| `src/fit.rs` | размер окна под видео |
| `src/playlist.rs` | логика плейлиста и M3U |
| `src/twitch.rs` | адрес потока по ссылке на канал Twitch |
| `src/youtube.rs` | адрес потока по ссылке на видео, эфир или канал YouTube |
| `src/sites.rs` | какой сайт стоит за ссылкой и как получить его поток |
| `src/chat.rs` | чат Twitch: подключение (IRC поверх WebSocket), разбор сообщений |
| `src/http.rs` | HTTPS-запросы самого плеера (запросы через `ureq`) |
| `src/live.rs` | прямые эфиры: распознавание, отставание от эфира, перемотка |
| `src/crop.rs` | кадрирование и вписывание кадра |
| `src/theme.rs` | тема и векторные иконки |
| `src/store.rs` | сохранённые позиции и настройки |
| `src/snapshot.rs` | сохранение кадра в PNG, папки «Изображения» и «Видео» |
| `src/clip.rs` | вырезка клипа без перекодирования (потоковый вывод libVLC) |
| `src/taskbar.rs` | кнопки под превью на панели задач Windows |
| `installer/` | установщик для Windows и скрипт сборки |
| `assets/` | иконка приложения (`icon.png`, `icon.ico`, ресурс для exe) |

Позиции и настройки лежат в `%APPDATA%\Resumo` (Windows),
`~/Library/Application Support/Resumo` (macOS) или `~/.config/resumo` (Linux).

Весь код плеера на Rust, без C/C++ и без генерации привязок. libVLC — это
библиотека на C, к ней плеер обращается через FFI, как любая программа на Rust
к системным библиотекам. Интерфейс сделан на egui/eframe (OpenGL).

`cargo test` проверяет плейлист, кадрирование, сохранение позиций и настроек, форматирование времени, иконки кнопок панели задач и распознавание HDR в mkv, mp4 и HEVC, имена и обрезку сохранённых кадров, отметки и параметры вырезки клипа. Саму вырезку на настоящем файле проверяет
`RESUMO_TEST_VIDEO=фильм.mkv cargo test -- --ignored cuts` (файл длиннее двух минут).
