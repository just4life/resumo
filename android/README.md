# VPlayer

Простой видеоплеер с современным тёмным интерфейсом. Написан на Rust, видео и звук
воспроизводит libVLC (движок из исходников VLC 3.x).

## Возможности

- **Плейлист**: файлы, папки, ссылки (http, rtsp, udp…), перетаскивание в окно,
  повтор (весь список / один трек), перемешивание, сохранение и загрузка M3U,
  переход к следующему файлу по окончании.
- **Аудиодорожки**: выбор дорожки, отключение звука, задержка звука.
- **Субтитры**: встроенные дорожки, загрузка внешнего файла (srt, ass, ssa, vtt, sub…),
  задержка субтитров. Файл субтитров можно просто перетащить в окно.
- **Кадрирование**: 16:9, 16:10, 4:3, 5:4, 1:1, 1.85:1, 2.35:1, 2.39:1, 9:16
  и ручная обрезка каждого края в процентах.
- **Звук**: выбор устройства вывода (колонки, наушники, HDMI) в меню правой кнопки,
  громкость до 150 %, регулировка колёсиком мыши над видео (шаг 5 %).
- **Продолжение просмотра**: плеер запоминает, где остановлено каждое видео,
  и при следующем открытии продолжает с этого места. Досмотренное до конца
  начинается сначала. Громкость и выбранное устройство тоже запоминаются.
- Скорость 0.25×–3× (в том числе 1.15×), полноэкранный режим, контекстное меню по правой кнопке на видео.

## Интерфейс

- Все кнопки собраны в одной полупрозрачной панели поверх нижней части видео.
  Пока видео играет, а мышь не двигается, панель и курсор скрываются.
- Кнопка с папкой в панели открывает файлы, папки и ссылки.
- Рамка окна своя, в теме плеера: перетаскивание за заголовок, двойной щелчок
  разворачивает окно, размер меняется за края.
- В Windows под превью окна на панели задач есть кнопки «предыдущий»,
  «пауза / воспроизведение» и «следующий», как у Spotify.

## Android

Та же программа, собранная под Android 7+ (arm64). Все функции десктопной версии
на месте; отличия только там, где у телефона нет мыши и окон:

- **Открытие файлов** — встроенный файловый браузер (память телефона, SD-карта,
  USB, сеть): касание файла сразу открывает его; чтобы открыть несколько,
  нажмите «Выделить» (или подержите палец на файле), отметьте файлы и нажмите
  «Открыть». Можно также взять всю папку, выбрать субтитры или место для
  сохранения M3U. При первом открытии плеер попросит доступ
  «ко всем файлам»: без него Android не показывает субтитры и плейлисты в папках.
- **Локальная сеть** — раздел «Сеть» в браузере: медиасерверы DLNA/UPnP
  (Plex, Kodi, Windows Media, роутеры) и общие папки SMB (компьютеры
  с Windows, NAS) находятся сами, если телефон в той же сети Wi-Fi. Адрес
  можно ввести и вручную, например `smb://192.168.1.10/Видео`. Если папка
  защищена паролем, плеер спросит имя пользователя и пароль и запомнит их
  для этого компьютера (файл `network-logins.tsv` в личной папке приложения,
  недоступной другим приложениям). Найденное открывается как обычные
  файлы.
- **«Открыть с помощью» → VPlayer** в файловом менеджере запускает файл в плеере
  (если плеер уже открыт, файл нужно открыть через его браузер).
- **Жесты на видео**: касание в центре ставит на паузу и снимает с неё,
  в остальных местах показывает и прячет панель; двойное касание слева
  или справа — −10 / +10 с, посередине — полный экран. Свайп вверх-вниз
  по левой половине меняет яркость, по правой — громкость плеера (тот же
  ползунок, до 150 %), свайп
  вбок перематывает (через весь экран — до 2 минут), значение видно
  на экране. Яркость меняется только для плеера. Долгое нажатие на видео
  открывает то же меню, что правая кнопка мыши; долгое нажатие на строку
  плейлиста — меню строки. Касание строки плейлиста сразу запускает её.
- На паузе вверху видео написано название файла.
- **Масштаб** (меню кнопки кадрирования): «Целиком», «Под экран» (без полос,
  лишнее по краям обрезается), «По ширине», «По высоте». Там же галочка
  «Убирать чёрные полосы в самом видео»: плеер сам находит полосы, вшитые
  в кадр (фильм 2.39:1 в кадре 16:9 и т. п.), и обрезает их; новая обрезка
  применяется, только если держится около полутора секунд, чтобы тёмные
  сцены не дёргали картинку. Выбор запоминается (файл `zoom.txt`).
- **Недавние** — последние 5 просмотренных файлов, в том числе из сети.
  Они видны в пустом плейлисте (или на пустом экране, если плейлист скрыт)
  и в меню кнопки с папкой; касание запускает файл с того места, где
  он был остановлен. Список хранится в файле `history.txt` в личной папке
  приложения.
- Плеер всегда занимает весь экран, без строки состояния. На телефонах
  с вырезом под камеру (Android 9+) видео доходит до самого края, вокруг
  камеры, а кнопки, меню и браузер держатся в стороне от выреза. **Полный экран**
  убирает плейлист и для горизонтального видео поворачивает экран.
  Пока видео играет, экран не гаснет.
- Вертикально плейлист стоит под видео, а кнопки панели — в два ряда.
  Когда файл выбран (в браузере или в плейлисте), плейлист прячется и видео
  занимает весь экран; кнопка плейлиста возвращает его.
- **Окно поверх других приложений**: если свернуть плеер, пока играет видео,
  оно продолжает играть в маленьком окне (Android 8+). На Android 12+
  так работает и кнопка «Домой», на Android 8–11 только «Назад». Касание
  окна показывает кнопку паузы и воспроизведения. Если окно
  закрыть или эта функция выключена в настройках телефона, видео ставится
  на паузу, музыка продолжает играть.
- Кнопка «Назад» закрывает браузер, окно или меню, выходит из полного экрана,
  а на главном экране сворачивает плеер.
- В окне ссылки есть кнопка «Вставить» из буфера обмена.
- Громкость телефона — кнопками громкости; ползунок плеера по-прежнему даёт до 150 %.

При первом запуске плеер один раз составляет список шрифтов телефона для
субтитров; в это время первые субтитры могут появиться с задержкой.

Проверить сборку на эмуляторе без аппаратной виртуализации можно только частично,
так что APK стоит проверить на телефоне.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | пауза / воспроизведение |
| ← / → | −5 / +5 с (с Shift: 30 с) |
| ↑ / ↓, колёсико | громкость |
| M | без звука |
| N / P | следующий / предыдущий |
| A | следующая аудиодорожка |
| S | следующие субтитры |
| C | следующий режим кадрирования |
| L | показать / скрыть плейлист |
| F, F11, двойной клик | полный экран (Esc — выйти) |
| Ctrl+O | открыть файлы |

## Готовые сборки

- `dist/VPlayer-Setup-0.1.0.zip` (внутри `VPlayer-Setup-0.1.0.exe`) — установщик для Windows 10/11 (64-бит).
  Ставит плеер в `Program Files\VPlayer`, создаёт ярлыки и регистрирует VPlayer
  для видео (mkv, mp4, avi, mov, webm, ts и др.), по желанию и для музыки.
  Windows 10/11 не позволяют программам молча назначать себя плеером по умолчанию,
  поэтому в конце установщик открывает «Приложения по умолчанию»: там нужно
  выбрать VPlayer. Удаляется через «Установленные приложения» и возвращает
  прежние ассоциации. Тихая установка: `VPlayer-Setup-0.1.0.exe /S`.
- `dist/VPlayer-windows-x64.zip` — переносная версия без установки: распаковать
  и запустить `VPlayer\vplayer.exe`. libVLC и плагины уже лежат рядом, VLC ставить не нужно.
- `dist/VPlayer-android-arm64.apk` — для Android 7 и новее (64-битные ARM,
  то есть почти все телефоны с 2017 года). Скопировать на телефон и открыть,
  разрешив установку из этого источника.
- `dist/vplayer-linux-x64` — для Linux, нужен установленный VLC
  (`sudo apt install vlc` или `libvlc5 vlc-plugin-base`).

## Сборка из исходников

Нужен свежий Rust через `rustup` (проверено на 1.97).

**Linux**

```sh
sudo apt install libvlc-dev vlc-plugin-base
cargo build --release
./target/release/vplayer video.mkv
```

**Windows (MSVC)**

1. Установить VLC 3.x (64-бит) или скачать NuGet-пакет `VideoLAN.LibVLC.Windows`.
2. Указать папку с `libvlc.lib`:
   `set VLC_LIB_DIR=C:\путь\к\build\x64` (для установленного VLC — его папка `sdk\lib`).
3. `cargo build --release`
4. Положить рядом с `vplayer.exe` файлы `libvlc.dll`, `libvlccore.dll` и папку `plugins`.

**Windows (кросс-сборка из Linux)**

```sh
sudo apt install gcc-mingw-w64-x86-64 nsis zip
rustup target add x86_64-pc-windows-gnu
VLC_LIB_DIR=/путь/к/VideoLAN.LibVLC.Windows/build/x64 sh installer/build-windows.sh
```

Скрипт собирает `vplayer.exe`, переносной zip и установщик
(`installer/vplayer.nsi`, NSIS 3) в папку `dist/`.

**Android**

Нужны Android SDK (build-tools, platform) и NDK (проверено на NDK 28.2,
build-tools 36), Java для `keytool`/`apksigner`, `zip`, `unzip`, `curl`.

```sh
rustup target add aarch64-linux-android
sdkmanager "ndk;28.2.13676358" "build-tools;36.0.0" "platforms;android-36"
ANDROID_HOME=/путь/к/sdk bash android/build-apk.sh
```

Скрипт скачивает libVLC для Android (`org.videolan.android:libvlc-all` 3.7.7
с Maven Central, или берёт готовый `.aar` из `VLC_AAR`), собирает `android/`
как `libvplayer.so` для NativeActivity, упаковывает APK с `libvlc.so`
и `libc++_shared.so`, подписывает ключом `android/vplayer.keystore`
(его надо сохранить: APK с другим ключом не установится поверх старого)
и кладёт результат в `dist/`. `ABI=x86_64` собирает версию для эмулятора.

**macOS**

Установить VLC.app в `/Applications`, затем `cargo build --release`.
Библиотека берётся из `/Applications/VLC.app/Contents/MacOS/lib`; если плагины
не находятся, запускать с `VLC_PLUGIN_PATH=/Applications/VLC.app/Contents/MacOS/plugins`.
Сборка под macOS не проверялась.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/vlc.rs` | привязки к C API libVLC (`extern "C"`) и безопасные обёртки |
| `src/video.rs` | приём кадров RGBA из потока libVLC |
| `src/app.rs` | окно, панель управления, меню, плейлист |
| `src/playlist.rs` | логика плейлиста и M3U |
| `src/crop.rs` | кадрирование и вписывание кадра |
| `src/theme.rs` | тема и векторные иконки |
| `src/store.rs` | сохранённые позиции и настройки |
| `src/taskbar.rs` | кнопки под превью на панели задач Windows |
| `src/browser.rs` | файловый браузер для Android |
| `src/lan.rs` | локальная сеть: поиск DLNA/SMB через libVLC, списки папок, вход по паролю |
| `src/history.rs` | недавние файлы (Android) |
| `src/zoom.rs` | масштаб «под экран / по ширине / по высоте» и поиск чёрных полос в кадре (Android) |
| `android/` | Android: точка входа, JNI (`platform.rs`), манифест, иконки, `build-apk.sh` |
| `installer/` | установщик для Windows и скрипт сборки |
| `assets/` | иконка приложения (`icon.png`, `icon.ico`, ресурс для exe) |

Позиции и настройки лежат в `%APPDATA%\VPlayer` (Windows),
`~/Library/Application Support/VPlayer` (macOS), `~/.config/vplayer` (Linux)
или в личной папке приложения (Android).

Весь код плеера на Rust, без C/C++ и без генерации привязок. libVLC — это
библиотека на C, к ней плеер обращается через FFI, как любая программа на Rust
к системным библиотекам. Интерфейс сделан на egui/eframe (OpenGL).
На Android тоже нет ни строчки Java: приложение — NativeActivity, а то немногое,
что нужно от системы (разрешения, яркость и поворот экрана, окно поверх других, буфер
обмена, multicast для поиска в сети, запуск Java-части libVLC через
`JNI_OnLoad`), вызывается из Rust через JNI. Код, который есть
только на Android, отделён `#[cfg(target_os = "android")]`, так что десктопные
сборки не меняются.

`cargo test` проверяет плейлист, кадрирование, сохранение позиций, форматирование времени и иконки кнопок панели задач.
