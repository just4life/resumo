# VPlayer

Видеоплеер на основе libVLC, написанный на Rust (egui). Эта ветка форка VLC содержит только исходники плеера; исходный код самого VLC находится в ветке `master`.

| Папка | Платформа |
|---|---|
| [`windows/`](windows/) | Windows (настольная версия) |
| [`android/`](android/) | Android |

Инструкции по сборке есть в README каждой папки.

Плеер использует libVLC, который распространяется по лицензии LGPL 2.1+.
