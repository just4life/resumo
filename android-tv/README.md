# Resumo TV

Простой видеоплеер с современным тёмным интерфейсом. Написан на Rust, видео и звук
воспроизводит libVLC (движок из исходников VLC 3.x).

## Возможности

- **Плейлист**: файлы, папки, ссылки (http, rtsp, udp…), перетаскивание в окно,
  повтор (весь список / один трек), перемешивание, сохранение и загрузка M3U,
  переход к следующему файлу по окончании.
- **Аудиодорожки**: выбор дорожки, отключение звука, задержка звука.
- **Субтитры**: встроенные дорожки, загрузка внешнего файла (srt, ass, ssa, vtt, sub…),
  задержка субтитров. Файл субтитров можно просто перетащить в окно.
- **Кадрирование**: 16:9, 16:10, 4:3, 5:4, 1:1, 1.85:1, 2.35:1, 2.39:1, 9:16
  и ручная обрезка каждого края в процентах.
- **Звук**: выбор устройства вывода (колонки, наушники, HDMI) в меню правой кнопки,
  громкость до 150 %, регулировка колёсиком мыши над видео (шаг 5 %).
- **Продолжение просмотра**: плеер запоминает, где остановлено каждое видео,
  и при следующем открытии продолжает с этого места. Досмотренное до конца
  начинается сначала. Громкость и выбранное устройство тоже запоминаются.
- Скорость 0.25×–3× (в том числе 1.15×), полноэкранный режим, контекстное меню по правой кнопке на видео.

## Интерфейс

- Все кнопки собраны в одной полупрозрачной панели поверх нижней части видео.
  Пока видео играет, а мышь не двигается, панель и курсор скрываются.
- Кнопка с папкой в панели открывает файлы, папки и ссылки.
- Рамка окна своя, в теме плеера: перетаскивание за заголовок, двойной щелчок
  разворачивает окно, размер меняется за края.
- В Windows под превью окна на панели задач есть кнопки «предыдущий»,
  «пауза / воспроизведение» и «следующий», как у Spotify.

## Android TV

Эта папка — версия для телевизоров и приставок на Android TV / Google TV
(Android 7+, ARM 32 и 64 бита). Всё управляется пультом: стрелки, OK, «Назад»,
кнопки воспроизведения. Приложение называется **Resumo TV**, появляется на
главном экране телевизора (баннер) и ставится рядом с телефонной версией.

- **Главный экран**: плитки «Файлы», «Сеть», «Ссылка» и «Плейлист» (если он не пуст),
  ниже «Продолжить просмотр» — последние 5 видео с местом остановки.
  «Назад» сворачивает приложение.
- **Файлы**: слева источники (память устройства, подключённые USB-диски и HDD под
  своими именами, карта памяти, «Сеть»), справа папка. Диск, подключённый при открытом
  окне, появится, когда окно откроют снова.
  OK на видео сразу запускает его, а остальные видео папки становятся плейлистом.
  «Смотреть всю папку» — с первого файла. Кнопка «Меню» на пульте добавляет
  видео в плейлист, не уходя из папки. «Назад» — на папку выше, влево — к источникам.
- **Отметки просмотра** (на диске, в «Сети» и в «Продолжить просмотр»): строка
  начатого видео закрашена полупрозрачным слоем на ту долю, что просмотрена, а справа
  место остановки («с 1:02:33»); у досмотренного — галочка «просмотрен». У мест,
  сохранённых прежними версиями, длина не известна, поэтому заливки нет до следующего
  просмотра. Просмотренным видео считается после 90% (дальше обычно титры), но место
  остановки при этом сохраняется, и его можно досмотреть. Список хранится в
  `watched.txt` рядом с `positions.tsv` (последние 3000 видео).
- **Сеть**: медиасерверы DLNA/UPnP и общие папки SMB находятся сами; адрес вроде
  `smb://192.168.1.10/Видео` вводится экранной клавиатурой приложения. Логин и пароль
  запоминаются для каждого компьютера или NAS.
- **Во время видео** (панель скрыта): OK — пауза и панель, влево/вправо — −10 / +10 с
  (если держать кнопку, шаг растёт до 30 и 60 с; перемотка применяется, когда
  кнопку отпустили), вверх/вниз — показать панель, «Назад» — стоп и на главный экран
  (место запоминается).
- **Часы**: пока панель видна, справа вверху текущее время (часовой пояс телевизора)
  и «закончится в …» — когда кончится видео при текущей скорости.
- **Панель**: строка перемотки и кнопки «Пауза», «Предыдущее», «Следующее», «Звук»,
  «Субтитры», «Изображение», «Скорость», «Плейлист». Каждая из последних открывает
  список справа: дорожки и задержка (влево/вправо по 100 мс), субтитры из файла,
  масштаб «Целиком / Под экран / По ширине / По высоте», «Убирать чёрные полосы»,
  кадрирование, скорость, файлы плейлиста, повтор и перемешивание.
- **Кнопки пульта** работают на любом экране: Play/Pause, Play, Pause, Stop,
  «следующий» / «предыдущий», перемотка назад / вперёд (по 30 с).
  Кнопки каналов P+ / P− во время видео сразу включают следующее / предыдущее видео
  плейлиста (следующую или прошлую серию), по кругу, как каналы.
  Цифры 0–9 во время видео переходят на 0–90% его длины, как на YouTube.
  Кнопки геймпада A и B работают как OK и «Назад».
- **Клавиатура своя**, внизу экрана: системная клавиатура многих телевизоров не
  открывается для приложения без Java-поля ввода. В окнах с полем ввода (ссылка,
  адрес, логин и пароль) поле сразу получает фокус и открывается клавиатура:
  английская (сначала) и русская раскладки, цифры, символы, «Aa», курсор ‹ ›, «Стереть». OK вводит
  букву, «Готово» переходит к следующему полю или кнопке, «Назад» прячет клавиатуру,
  OK на поле открывает её снова.
- **Видео декодирует аппаратный декодер телевизора** (MediaCodec): libVLC
  включает его только по просьбе (`--codec=mediacodec_ndk,mediacodec_jni,all`, как
  в VLC для Android), а без этого 4K HEVC декодировал процессор и не успевал.
- **Видео идёт отдельным слоем под интерфейсом, с настоящим HDR**, как в VLC:
  декодер телевизора рисует кадр прямо в слой экрана (`SurfaceView`, который
  приложение ставит под своё окно, с `AWindow` из Java-части libVLC, она в APK),
  а интерфейс поверх него прозрачен там, где видео. Кадры не проходят ни через
  процессор, ни через текстуру, а HDR10 уходит на телевизор как есть: декодер сам
  помечает кадры как HDR, и телевизор переключается в режим HDR. Слой
  ставится по масштабу и обрезке, выбранным в панели «Изображение».
  Так libVLC выводит видео своим модулем `android_display` (`--vout=android_display,any`);
  он открывается, только если у `AWindow` есть слушатель раскладки видео, и им
  служит собственный `VideoHelper` из libVLC, созданный без конструктора (он
  ничего не делает: место слоя задаёт приложение). Без этого libVLC брал
  OpenGL-вывод.
- **«Вывод видео»** в панели «Изображение», если на каком-то телевизоре слой не
  работает: «Видеослой (HDR)» (по умолчанию), «Видеокарта» (кадр как текстура,
  HDR переводится в обычные цвета) и «Процессор» (старый способ, кадры через
  процессор). После смены приложение закроется, его нужно открыть снова.
- **HDR → SDR** (только для «Видеокарты»): HDR10-видео (PQ, BT.2020) переводится в
  цвета обычного экрана. По умолчанию «Авто» (включается для 10-битного
  HEVC/VP9/AV1 4K), в панели «Изображение» можно выбрать «Вкл» или «Выкл».
- **Файлы с дисков читаются наперёд**: отдельный поток читает видео блоками по 4 МБ
  в буфер на 96 МБ (около 10 секунд 4K-ремукса), поэтому заминки чтения USB-диска
  через слой FUSE Android 11 не останавливают картинку. Где система разрешает,
  диск читается напрямую (`/mnt/media_rw`), минуя FUSE. Субтитры рядом с видео
  (с тем же именем) подключаются сами.
- **Android 11** (проверено в эмуляторе Android TV 11): диски берутся
  из списка томов системы. Доступ к файлам: сначала страница «Доступ ко всем файлам»,
  а если телевизор её не показывает или доступ не дали, при следующем нажатии —
  обычный запрос разрешения.
- Доступ к файлам: где телевизор позволяет — «ко всем файлам», иначе обычное
  разрешение на видео и музыку (тогда в папках не видно файлов субтитров).
- Интерфейс рассчитан на экран высотой 540 точек и масштабируется под любое
  разрешение телевизора (720p, 1080p, 4K).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | пауза / воспроизведение |
| ← / → | −5 / +5 с (с Shift: 30 с) |
| ↑ / ↓, колёсико | громкость |
| M | без звука |
| N / P | следующий / предыдущий |
| A | следующая аудиодорожка |
| S | следующие субтитры |
| C | следующий режим кадрирования |
| L | показать / скрыть плейлист |
| F, F11, двойной клик | полный экран (Esc — выйти) |
| Ctrl+O | открыть файлы |

## Готовые сборки

- `dist/Resumo-androidtv.apk` — для Android TV / Google TV 7 и новее (ARM 32 и 64 бита).
  Как поставить: скопировать на флешку и открыть файловым менеджером телевизора,
  или передать через приложение вроде «Send files to TV» / Downloader, разрешив
  установку из этого источника.
- `dist/Resumo-androidtv-x86.apk` — та же версия для эмулятора Android TV.

Сборки для Windows, Linux и телефонов лежат в папках `player` и `player-android`.

## Сборка из исходников

Нужен свежий Rust через `rustup` (проверено на 1.97).

**Linux**

```sh
sudo apt install libvlc-dev vlc-plugin-base
cargo build --release
./target/release/resumo video.mkv
```

**Windows (MSVC)**

1. Установить VLC 3.x (64-бит) или скачать NuGet-пакет `VideoLAN.LibVLC.Windows`.
2. Указать папку с `libvlc.lib`:
   `set VLC_LIB_DIR=C:\путь\к\build\x64` (для установленного VLC — его папка `sdk\lib`).
3. `cargo build --release`
4. Положить рядом с `resumo.exe` файлы `libvlc.dll`, `libvlccore.dll` и папку `plugins`.

**Windows (кросс-сборка из Linux)**

```sh
sudo apt install gcc-mingw-w64-x86-64 nsis zip
rustup target add x86_64-pc-windows-gnu
VLC_LIB_DIR=/путь/к/VideoLAN.LibVLC.Windows/build/x64 sh installer/build-windows.sh
```

Скрипт собирает `resumo.exe`, переносной zip и установщик
(`installer/resumo.nsi`, NSIS 3) в папку `dist/`.

**Android TV**

Нужны Android SDK (build-tools, platform) и NDK (проверено на NDK 28.2,
build-tools 36), Java для `keytool`/`apksigner`, `zip`, `unzip`, `curl`.

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi
sdkmanager "ndk;28.2.13676358" "build-tools;36.0.0" "platforms;android-36"
ANDROID_HOME=/путь/к/sdk bash android/build-apk.sh
```

Скрипт скачивает libVLC для Android (`org.videolan.android:libvlc-all` 3.7.7),
собирает `android/` как `libresumo.so` для arm64-v8a и armeabi-v7a, упаковывает
один APK вместе с Java-частью libVLC (`classes.jar` из пакета, переведённый `d8`
в `classes.dex`; нужна для вывода видео на видеокарту), подписывает ключом
`android/resumo.keystore` и кладёт
`dist/Resumo-androidtv.apk`. `ABIS=x86` собирает версию для эмулятора Android TV
(`system-images;android-30;android-tv;x86`).

## Устройство

| Файл | Что внутри |
|---|---|
| `src/vlc.rs` | привязки к C API libVLC (`extern "C"`) и безопасные обёртки |
| `src/video.rs` | приём кадров RGBA из потока libVLC |
| `src/app.rs` | окно, панель управления, меню, плейлист |
| `src/playlist.rs` | логика плейлиста и M3U |
| `src/crop.rs` | кадрирование и вписывание кадра |
| `src/theme.rs` | тема и векторные иконки |
| `src/store.rs` | сохранённые позиции, отметки просмотра и настройки |
| `src/taskbar.rs` | кнопки под превью на панели задач Windows |
| `src/browser.rs` | браузер файлов и сети под пульт |
| `src/tv.rs` | кнопки пульта и крупные элементы с фокусом |
| `src/tv_app.rs` | экраны TV: главный, видео с панелью, боковые списки |
| `src/lan.rs` | локальная сеть: поиск DLNA/SMB через libVLC, списки папок, вход по паролю |
| `src/history.rs` | недавние файлы (Android) |
| `src/osk.rs` | экранная клавиатура для пульта (Android TV) |
| `src/zoom.rs` | масштаб «под экран / по ширине / по высоте» и поиск чёрных полос в кадре (Android) |
| `android/` | Android: точка входа, JNI (`platform.rs`), вывод видео слоем и на видеокарту, HDR → SDR (`surface.rs`), чтение файлов наперёд (`readahead.rs`), манифест, иконки, `build-apk.sh` |
| `installer/` | установщик для Windows и скрипт сборки |
| `assets/` | иконка приложения (`icon.png`, `icon.ico`, ресурс для exe) |

Позиции и настройки лежат в `%APPDATA%\Resumo` (Windows),
`~/Library/Application Support/Resumo` (macOS), `~/.config/resumo` (Linux)
или в личной папке приложения (Android).

Весь код плеера на Rust, без C/C++ и без генерации привязок. libVLC — это
библиотека на C, к ней плеер обращается через FFI, как любая программа на Rust
к системным библиотекам. Интерфейс сделан на egui/eframe (OpenGL).
На Android тоже нет ни строчки Java: приложение — NativeActivity, а то немногое,
что нужно от системы (разрешения, яркость и поворот экрана, окно поверх других, буфер
обмена, multicast для поиска в сети, запуск Java-части libVLC через
`JNI_OnLoad`, поверхности для видео), вызывается из Rust через JNI. Java-классы в APK
— только готовая часть самого libVLC. Код, который есть
только на Android, отделён `#[cfg(target_os = "android")]`, так что десктопные
сборки не меняются.

`cargo test` проверяет плейлист, кадрирование, сохранение позиций и отметок просмотра, форматирование времени и иконки кнопок панели задач.
